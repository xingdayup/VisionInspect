# GPU 质检业务

当前用户确认范围是完整中文工作台，PatchCore 与 VLM 均使用 GPU。仅提供 GPU 单模型与 Agent 多步复核。当前有可迁移模型的类别为 bottle。

1. 单图或网页多图上传，每批最多 100 张；单文件 10 MiB、1600 万像素。图片独立校验，错误可见，成功项保留。
2. 质量通过后执行冻结 PatchCore。不确定区间外按规则输出候选；不确定区间内由 Agent 选择局部比较、切换参考或结束。
3. 接受正常复核需要有效正常训练参考、所有疑似区域已做对应局部检查、证据一致且无可见异常。缺失、矛盾、模糊、超时及预算耗尽转人工。
4. 人工逐项追加状态和说明，保留原始模型和 Agent 判断。没有产品规范时不推断公差、缺陷成因或工业放行。
5. 单图 JSON、批次 JSON/CSV 包含来源、证据和调用轨迹。候选比例不叫产品合格率。

批次先建草稿，上传后手动启动；全局待执行上限 200，串行调度。暂停/取消在当前图片完成后生效。重试创建关联新任务，原尝试保留；汇总按每张图片最新尝试计算。重启时执行中任务失败，批次暂停，排队项保留。

旧 CPU VLM 与 fixed/dynamic 工作流已移出当前产品。GPU 数值与新 Agent 收益必须通过实际设备、独立验证或标注数据证明，不引用旧 CPU 实验作为完成依据。
