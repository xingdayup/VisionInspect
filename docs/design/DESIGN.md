# VisionInspect 工作台设计

## Physical scene and theme

操作者在明亮办公室的 Windows 桌面显示器上连续查看产品细节，浅色中性界面降低与真实图像背景之间的视觉干扰。

## Color strategy

Restrained：冷灰中性表面配少量铜棕操作强调，强调色用于提交按钮、选择和焦点。语义绿、黄、红仅表示候选状态和错误。全部令牌使用 OKLCH，文字不使用纯黑，背景不使用纯白。

## Typography

Segoe UI、Microsoft YaHei UI、系统无衬线。14px 基准，标题 24px，分节标题 16px；数字使用 tabular-nums。说明文字不超过 72ch。

## Layout and components

桌面采用 208px 导航栏、简洁顶栏、上传区与最近任务列表。任务完成后进入视觉证据页，主图并列显示，参考与裁剪图逐层展开。轨迹使用按顺序展开的列表，历史使用表格，系统状态使用定义列表。只给确有独立语义的面板加边框，不嵌套卡片。

导航为工作台、批量质检、视觉证据、执行轨迹、检测历史、报告、系统状态。按钮、文件输入、select、details、表格沿用熟悉的原生语义。窄屏导航横向排列，双列内容改为单列，表格提供水平滚动。

## States and motion

处理中禁用重复提交，使用文字阶段和原生 progress；空状态给出下一操作。HTTP 超时、后端不可用、文件错误、模型缺失均提供明确反馈与重试。所有图片有用途描述。仅采用 160ms 色彩过渡，支持 prefers-reduced-motion。

## Task brief

范围为全部必需页面、真实 REST 轮询、上传和复核、JSON 报告导出与响应式布局，交付可运行代码。用户已授权自主完成方向，因此不增加额外设计确认。参考 Windows 文件管理器的操作稳定性、GitHub 的证据与记录层次。图片均为检测证据，不使用装饰性插图。本次无需栅格视觉探索，明确的工作台结构与证据阅读任务已确定，直接通过浏览器实测布局。

用户确认 v0.4 批量质检与自动研究复核：每批最多 100 张网页多图上传，逐项人工记录；延续现有色彩、字体与桌面布局。结论分原始检测、Agent 复核、人工记录三层，GPU 未配置时明确禁用新工作流。真实图片用于证据，不增加装饰图。
